### 🤖 AI Lost & Found Matching System

> **Intelligent semantic matching engine for lost and found items**

```text
Stack  →  Python · NLP · Embeddings · LLMs · Semantic Similarity
Status →  🚀 Live
Scope  →  Candidate filtering · Semantic matching · Conflict detection · LLM reranking
```

An **AI-powered matching system** designed to identify potential matches between lost and found item reports.

The matching pipeline combines deterministic structured matching with **semantic embedding similarity**, explicit compatibility/conflict detection, confidence scoring, and **LLM-based reranking** of the strongest candidates.

The system was evaluated against a dedicated test dataset with strong performance across matching and retrieval metrics.
